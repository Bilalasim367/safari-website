SAFARI PERFUMES - CPANEL DEPLOYMENT (NO TERMINAL REQUIRED)
============================================================

This package is ALREADY BUILT. You do NOT need Terminal, SSH, or npm.
Just upload, extract, create the Node.js App, set env vars, and Start.

THE 3 ZIP FILES
---------------
- deploy-app-core.zip      (app + server + node_modules + Prisma)  ~65MB
- deploy-app-assets-1.zip  (banners + root images + uploads)       ~54MB
- deploy-app-assets-2.zip  (product images)                        ~62MB

1) UPLOAD + EXTRACT (cPanel -> File Manager)
   a) Go to /home/yourusername
   b) Click "Create New Folder" -> name it: deploy-app
   c) Enter that folder, then upload and extract EACH zip IN THIS ORDER:
      1. deploy-app-core.zip
      2. deploy-app-assets-1.zip
      3. deploy-app-assets-2.zip
      All three must be extracted inside the SAME deploy-app folder so
      the files merge together (public/ images + server.js + node_modules).

2) CREATE NODE.JS APP (cPanel -> Setup Node.js App)
   - Click "Create Application".
   - Application root : deploy-app  (the folder from step 1)
   - Application URL / domain : your domain or subdomain
   - Node.js version  : 22.x (e.g. 22.23.2 if listed). Next.js 16 needs Node >= 20.9.
   - Application startup file : server.js
   - Leave the rest default. Save.

3) ENVIRONMENT VARIABLES (Setup Node.js App -> your app -> Environment Variables)
   Add these EXACTLY (use the same production values as your local .env):
     NODE_ENV                  = production
     NEXT_PUBLIC_BASE_URL      = https://yourdomain.com
     NEXT_PUBLIC_API_URL       = https://yourdomain.com
     TURSO_DATABASE_URL        = libsql://...
     TURSO_AUTH_TOKEN          = <your token>
     JWT_SECRET                = <your secret>
     ADMIN_SECRET_KEY          = <your secret>
     BLOB_READ_WRITE_TOKEN     = <your token>
   IMPORTANT: the server.js runtime does NOT read .env in production,
   so these MUST be set here or the app will crash or show blank pages.

4) START THE APP
   - Go back to Setup Node.js App and click "Start".
   - Wait ~30 seconds, then open your domain in the browser.

5) CHECK ERRORS (if the site shows a Passenger/error page)
   - Setup Node.js App -> click your app -> "Logs".
   - Copy the lines around the Error ID and send them to me.

6) SSL
   - cPanel -> SSL/TLS Status -> make sure AutoSSL (Let's Encrypt) covers your domain.
   - If you need to force https:// ask me for the .htaccess snippet.

NOTES
- No Terminal / SSH / npm is used anywhere in this process.
- The app is pre-built for production on Node 22.x.
- Never upload this zip package to a public place - it contains compiled app code
  but NO secrets (env vars are set only in cPanel).
